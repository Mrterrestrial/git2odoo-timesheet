# Task catalogue

Shared file for everyone on the project: one entry per Odoo task of the project with what belongs
to it. The description engine uses it to pick the task for a day's work, so a designer, a backend
developer and a devops engineer map their commits correctly with the same list. The task names must
match the Odoo task names exactly.

## Development
Code on the main application: features, fixes, refactoring.

## Infrastructure
Servers, CI/CD, Docker, monitoring, security hardening, backups.

## Design
Mock-ups, UI components, style guides, assets.

## Meeting
Calls and meetings with the client or the team.

## Support
Helpdesk tickets, bug investigation requested by users, data fixes.

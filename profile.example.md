# Profile

Personal file: who you are on the project and what you are doing these days. It is sent, together
with `tasks.md`, to the description engine so the suggested task and wording fit your role.
Copy to `profile.md` and keep it short. Markdown headings are free text except `## Current focus`,
which the tool rewrites when you run `timesheet.py focus "..."` or save the box on the review page.

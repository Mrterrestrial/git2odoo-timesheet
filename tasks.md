# Task catalogue — Auto A Pezzi (Odoo project 17)

Shared by everyone on the project. One entry per Odoo task, with what belongs there. Names must match
Odoo exactly. Adjust the wording as the team sees fit; the engine reads this file on every run.

## practica
Dossiers / demolition requests ("pratiche"): request lifecycle and statuses, documents and their
verification, applicant and vehicle-owner data, demolisher assignment, summary PDFs, dossier e-mails,
B2B and B2C (private) demolition flows, suspension and cancellation.

## Opportunità
Marketplace opportunities: creation forms and templates, vehicle specs on an opportunity, offers,
awards, channel and company settings, opportunity PDFs and e-mails, payments and card handling
(Saferpay, Worldline), fees, refunds, referral codes.

## Funzionalità aste
Auction rules specifically: bidding windows, minimum offers, offer validity, bidder masking, what a
bidder may see or do, closed-listing behaviour.

## Veicoli abbandonati
Abandoned-vehicle flow: reports, custody periods, status labels per audience, handler assignment,
documents visible to reporters and viewers.

## Backoffice
The admin backoffice (React SPA) and the Django admin: admin screens, lists, filters, exports,
dashboards and their statistics endpoints, admin permissions, company and user management,
cache invalidation for admin views.

## Sviluppo Backoffice "Smart"
New-generation backoffice features planned as a separate stream. Use `Backoffice` unless the team
assigns work explicitly to this stream.

## Sviluppo Backoffice Attuale
